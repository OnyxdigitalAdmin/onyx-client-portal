# Onyx Client Portal

Vite + React + TypeScript + Tailwind CSS, with the Supabase JS client wired up.

## Setup

```bash
npm install
cp .env.local.example .env.local # if present, otherwise create manually
```

Fill in `.env.local` with your Supabase project credentials:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```
