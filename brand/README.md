# Onyx Digital brand assets

Source of truth for all visual/brand decisions on the client portal. Use these — not invented colors, fonts, or logos — for every UI surface built from here on.

- `tri-bunny-logo-onyx-digital.png` — primary mark, full color
- `tri-bunny-white-transparent.png` — primary mark, white, transparent background (for dark surfaces)
- `onyx-digital-text-logo-with-bunnies-transparent.png` — wordmark + mark lockup, transparent background
- `onyx-digital-logo-banner.png` — wide banner lockup

## fonts/
- `Shree714.ttc` — internally "Shree Devanagari 714" (TrueType collection, Regular/Bold/Italic/Bold Italic). Confirmed and approved as the typeface across the entire build via its bundled Latin glyphs — checked to render standard Latin/English lettering correctly. No substitution needed.

## color-palette/
- `color-palette.png` — reference swatch sheet
- Full approved palette (see `DESIGN.md` for the canonical, structured version — this is a quick reference):
  - `#3f3fc1` — Primary: buttons, links, active states
  - `#1818ac` — Primary Dark: headers, emphasis
  - `#FAFAFC` — Background: page background
  - `#1E1B3A` — Text: body copy
  - `#E2E1F0` — Border: dividers, card edges
  - `#2F9E6E` — Complete: status = 100%/done
  - `#C68A2E` — Attention: status = in progress/open items (deliberately amber, not red)
  - `#B84C4C` — Error: real errors only (deliberately muted, not harsh red)
- This is the full approved palette — applies to every screen, including Onboarding Mode and Management Mode.
