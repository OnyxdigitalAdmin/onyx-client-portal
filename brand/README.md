Source of truth for all visual/brand decisions on the client portal. Use these — not invented colors, fonts, or logos — for every UI surface built from here on.

- `tri-bunny-logo-onyx-digital.png` — primary mark, full color
- `tri-bunny-white-transparent.png` — primary mark, white, transparent background (for dark surfaces)
- `onyx-digital-text-logo-with-bunnies-transparent.png` — wordmark + mark lockup, transparent background
- `onyx-digital-logo-banner.png` — wide banner lockup

## fonts/
- `Shree714.ttc` — brand typeface (TrueType collection, 4 weights/styles)

## color-palette/
- `color-palette.png` — reference swatch sheet
- Sampled values from the swatch sheet:
  - `#3f3fc1` — lighter indigo/periwinkle
  - `#1818ac` — darker indigo/blue
- Treat these two as the core brand blues. Confirm any additional accent/neutral colors with the user before inventing them — do not assume a full palette (backgrounds, grays, semantic colors) beyond what's shown here.

## ui-reference/
- `landing-page-reference.png` — reference for landing/marketing page layout and feel
- `web-form-reference.png` — reference for form UI treatment
- These are references for direction and craft level, not literal specs to clone — reconcile with the "Clarity-First" tone in the root `CLAUDE.md` (calm, plain-language, never fear-based/red-dashboard styling).
